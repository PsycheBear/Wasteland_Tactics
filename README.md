# Wasteland Tactics

A post-apocalyptic auto-battler built with React and Vite. Draft units, manage your economy, equip items, and battle through increasingly difficult rounds in a Fallout-inspired wasteland.

## Features

- **Unit drafting & synergies** — Build a team from a shared pool of units, each with unique traits that unlock powerful synergy bonuses.
- **Item crafting** — Collect item components after PvE rounds and combine them into completed items to equip on your units.
- **Augments** — Choose from augment options at key rounds to customize your strategy.
- **Boss encounters** — Face off against unique bosses with special abilities.
- **Auto-combat** — Watch your squad fight it out with animated attacks, abilities, and floating damage numbers.
- **Save & continue** — Progress is saved to local storage so you can pick up where you left off.

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Tech Stack

- React 18
- Vite 6
